# 龙潭商业街

《龙潭商业街》是一款以湖南桂阳县为背景的像素风网页经营游戏。作为桂阳一中的毕业生，你回到街坊熟悉的龙潭街，经营一间炸物摊。

## 开始经营

- 在地图上点红棚的「龙潭炸香摊」，或用方向键移动到摊前按 E。手机可以用虚拟摇杆移动，再点击互动按钮。
- 接待顾客，按订单拿食材。第一次休闲营业会依次介绍炸土豆、炸豆腐和油炸肉丸。
- 按工作台提示处理食材，火候指针进入绿区后捞起，调味装盘，再交给顾客。
- 休闲经营可以慢慢做。限时挑战从接单开始计时，离开经营面板时暂停。
- 收摊时结算当天菜款、小费、任务奖励、采购和升级成本。完成目标即可领奖，也可以提前收摊。
- 到仓库或补货点采购，在炸香摊查看设备升级、菜谱熟练度与每日目标。地图上的四家筹备摊位可查看菜单计划和条件。

地图按桂阳一中和龙潭商业街的地理印象原创绘制。首发开放炸香摊，后续更新逐家开业。

## 存档

进度自动保存在当前浏览器及网址对应的本地存储中。换设备、换网址和清理浏览器数据都会影响读取。通过「设置 → 导出存档」备份，再用「导入存档」迁移角色、库存和正在制作的订单。清空存档和替换现有进度均有确认步骤。浏览器无法写入存档时，仍可导出当前会话的进度。

## 本地运行

需要 Node.js 24 和 pnpm 11。可用 `npm install --global pnpm@11.25.0` 安装项目使用的 pnpm 版本。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

访问 [本地开发地址](http://127.0.0.1:5173/)。生产构建输出到 `dist/`。

```sh
pnpm test
pnpm run build
pnpm exec playwright install chromium
pnpm run test:e2e
```

浏览器测试读取 `dist/`，并通过临时 HTTP 服务从 `/longtan-street/` 访问。已安装 Microsoft Edge 的 Windows 可在 PowerShell 设置 `$env:PLAYWRIGHT_EDGE='1'`，再运行浏览器测试。

## 部署

仓库 Settings → Pages 的来源设为 GitHub Actions。推送 `main` 上的源码后，`.github/workflows/pages.yml` 会安装锁定的依赖、运行单元测试、构建并发布静态产物。也可以在 Actions 手动运行。Vite 使用相对资源路径，适用于仓库子目录。直接用文件管理器打开 `dist/index.html` 时，浏览器可能拦截模块脚本，请通过 HTTP 预览。

## 内容维护

- `src/content.ts` 存放菜谱步骤、食材价格、顾客、摊位、每日目标及设备。
- `src/world.ts` 存放地图尺寸、碰撞与交互对象，以及 NPC 路线。
- `src/business.ts` 处理营业和结算。烹饪状态与订单一起保存。
- `src/save.ts` 负责版本、迁移登记、导入校验与本地备份。新增可存档实体时使用稳定字符串编号。调整既有配方步骤时应同时处理正在制作的旧存档。
